> 完成：片疤成为独立对象（`annotations.scars`，箭头为可选的 `vector`），新增 `specimen.frame` 与 `derived`；`formatVersion` 2，v1 文件读入时自动迁移，箭头 CSV 不变。

## 阶段 1　测量与平面

### 1.1 基础测量（测量模式） ✅ 2026-10-17

> 完成：打开模型即分帧计算长宽厚、表面积、体积（仅封闭）、Surface-to-Volume Ratio、Wadell 球度；手动测量直线 / 沿表面 / 角度（M1…，可撤销，存入项目文件）；两种 CSV。

**自动测量**（打开模型即算，显示在测量模式侧栏）：

- 长、宽、厚：模型在三个轴上的投影范围。有标本坐标系时用它（Y 长、X 宽、Z 厚）；没有时用面积加权主轴（第一主轴为长）。记录用的是哪种（`frame` = `specimen` / `principal`）。
- 表面积 A。
- 体积 V：只在模型封闭时计算。不封闭时显示「未封闭」，体积相关的值留空，不自动补洞。
- **Surface-to-Volume Ratio** = A / V^(2/3)，无量纲。中英文界面都用这个名称，CSV 列名 `surface_to_volume_ratio`。
- Wadell 球度 ψ = π^(1/3)·(6V)^(2/3) / A，CSV 列名 `wadell_sphericity`。

**手动测量**（作为标注保存，可撤销，列表编号 M1、M2……）：

- 两点直线距离；
- 两点沿表面距离：用现有 `PathSearch`（吸附关闭）连接两点，再用 `relaxPath` 拉紧，显示路径；
- 三点角度：中间的点为顶点，单位为度。

**导出**：

- `<标本>_measurements.csv`，每件一行：`specimen_id, unit, frame, length, width, thickness, surface_area, volume, surface_to_volume_ratio, wadell_sphericity, closed`
- `<标本>_manual_measurements.csv`，每条一行：`specimen_id, measure_id, type (distance / geodesic / angle), value, unit, p1_x … p3_z`（用不到的点留空；角度的 unit 为 `deg`）

**验收**：立方体、球的已知值；不封闭模型的体积留空；手动测量的撤销、重做、保存往返。

### 1.2 拟合平面 ✅ 2026-10-17

> 完成：四种方法、法向按 upHint 定向（可翻转）、平面坐标系矩阵；输入变化即重算；圆盘 + 交线 + 法向箭头，逐个显示 / 隐藏、沿法向观察；平面 CSV。

四种方法（代码 / 定义）：

1. `all_vertices`（Lin et al. 2024）：对模型全部顶点做最小二乘平面，不加权，与 Geomagic「Best Fit」选全部点的做法一致。中心 = 全部顶点的均值。
2. `scar_directions`（Xiao et al. 2026）：全部片疤方向的单位向量，不加权；方向张量 T = Σ u·uᵀ，法向 = T 最小特征值对应的特征向量（即与所有片疤方向最平行的平面）。中心 = 全部片疤中点（起点与终点的中点）的均值。
3. `scar_starts`：片疤起点的最小二乘平面。可按完整性类型筛选：默认全部选中，使用者可以排除任意类型（例如 `both_missing`）。点几乎共线时不提示。中心 = 所用起点的均值。
4. `curves`：一条或多条曲线，开放或闭合都可以。先按等弧长重新取点，再做最小二乘平面。中心 = 重新取点后的均值。

其他规则：

- 输入不足时平面无效：少于 3 个点，或 `scar_directions` 少于 2 个不平行的方向。界面显示为无效状态。
- **法向朝向**：创建时默认指向当前观察者，记录为 `upHint`；法向始终取与 `upHint` 同侧。「翻转」即把 `upHint` 取反。
- 平面是派生对象：所用片疤、曲线或筛选条件变化时自动重算。
- **平面坐标系**（用于变换矩阵）：原点 = 中心；+Z = 法向；+X = 模型第一主轴（全部顶点 PCA）在平面上的投影，单位化，符号取使其绝对值最大的分量为正；+Y = Z × X。若第一主轴与法向几乎平行，改用第二主轴。

可视化：

- 半透明圆盘（半径覆盖模型在平面上的投影）、平面与模型表面的交线、法向箭头。
- 每个平面一种颜色，可单独显示或隐藏。
- 「沿法向观察」把视角转到垂直于平面。

侧栏：平面列表（P1、P2……）；检查面板只有方法、输入（曲线选择 / 完整性筛选）、翻转、沿法向观察、删除。

导出 `<标本>_planes.csv`，只含：`specimen_id, plane_id, method, center_x, center_y, center_z, normal_x, normal_y, normal_z, m00 … m33`。其中 m 为 4×4 变换矩阵，行主序，把原始坐标变换到平面坐标系。

验收：

- 已知平面上的点；已知环带分布的方向；倾斜圆周上的曲线，其中只取一段开放的弧也能恢复平面；
- 矩阵把中心映到原点、法向映到 +Z；
- 输入变化后平面更新；撤销正确。

## 阶段 2　展示模式

### 2.1 标本定向 ✅ 2026-10-17

> 完成：展示模式里以当前视角或平面法向为正视、箭头定纵轴、±90° 与微调；只记录矩阵，相机按矩阵摆放；长宽厚随之按标本坐标系计算。

  - 可选「以某个箭头定纵轴」。

- 默认按欧洲惯例：石片和石叶近端（台面）朝下、背面为正视面；石核的正视面和朝向由使用者决定。

### 2.2 标准正投影视图与出图 ✅ 2026-10-17

> 完成：六个视图任选、第一角投影排版；左上方掠射光；叠加层开关；PNG（透明、实物比例、dpi 写入文件）与 SVG（mm、矢量叠加与外轮廓、遮挡部分不画）。比例尺像素长度、背景透明、SVG 结构在测试中核对。

- **视图**：正面、背面、左、右、上、下，可任选几个。
- **排版：欧洲惯例（ISO 第一角投影）**
  - 从左侧看到的视图放在正视图右侧，从右侧看到的放在左侧；
  - 从上看到的放在正视图下方，从下看到的放在上方；
  - 背面放在最右侧（左视图的右边）；
  - 所有视图比例相同、相互对齐。
- **光照**：掠射光，默认来自图面左上方（石器线图惯例），高度角可调。
- **叠加层**逐项开关：片疤箭头、曲线、平面交线、地标、区域着色、比例尺。
- **比例尺**：公制，水平线带刻度（例如每 10 mm 一大格），单位取自 `specimen.unit`。单位未注明时不可用。
- **PNG**：透明背景；按实物比例（默认 1:1，可选 2:1、1:2）和 dpi（300 / 600 / 1200）输出。
- **SVG**：模型明暗作为内嵌位图；箭头、曲线、平面交线、地标、比例尺和外轮廓为矢量，被模型遮挡的部分不画；尺寸以 mm 为单位。
- 验收：
  - 导出图里比例尺的像素长度与实物比例一致（测试中按像素核对）；
  - 背景透明；
  - SVG 结构合法，Inkscape 能打开。

### 2.3 截面（仅用于展示） ✅ 2026-10-17

## 阶段 3　表面区域

### 3.1 曲线网络自动分区 ✅ 2026-10-18

> 完成：曲线端点吸附已有曲线；曲线→网格边链→连通分区，曲线变化即重算；种子点定类型（1–4），关联片疤或新建无方向片疤，冲突提示；着色、面积、各类型总面积与石皮比；区域 CSV 与测量 CSV 新列。

- **曲线工具增强**：曲线端点可以吸附到已有曲线上，形成 T 形交接，这样几条曲线能围成封闭区域。
- **分区**：
  - 把每条曲线换算成一串网格边：曲线点就近取顶点，相邻顶点之间用最短路相连。
  - 以这些网格边为界，对面片做连通分区，每个连通块是一个候选区域。
  - 曲线变化时自动重算。
- **类型**：`scar` 片疤（人工改造）、`cortex` 石皮、`joint` 节理面（未改造）、`damage` 破损。点击候选区域后选类型（数字键 1–4）。
- **保存方式**：区域保存为「种子点」，即点击处的表面坐标、类型和片疤 id。重算后，包含种子点的连通块继承类型；两个种子落进同一块时提示冲突。
- **与片疤对象关联**：区域内有箭头起点时，自动关联该片疤；没有时新建一个无方向的片疤。
- **显示**：按类型半透明着色（片疤区域可按片疤区分），可开关。
- **计算**：各区域面积、各类型总面积、石皮比 = 石皮面积 / 总表面积。
- **导出**：
  - `<标本>_regions.csv`：`specimen_id, region_id, type, scar_id, area, unit`
  - `_measurements.csv` 增加：`area_scar, area_cortex, area_joint, area_damage, cortex_ratio`
- **验收**：在合成模型上用曲线围出已知区域，面积与解析值之差在网格分辨率允许的范围内；曲线修改后区域类型保持不变。

### 3.2 石皮拟合球 ✅ 2026-10-18

> 完成：选定石皮区域（默认全部）的顶点做代数初值 + 几何迭代的球面拟合，给出半径、球心、残差 RMS，可显示线框球；测量 CSV 增加 `nodule_radius, nodule_fit_rms`。

- 对选定的石皮区域（默认全部）做球面最小二乘拟合：先用代数解求初值，再做几何迭代精化。输出半径、球心、残差 RMS。三维中可显示拟合球（线框）。
- 导出：`_measurements.csv` 增加 `nodule_radius, nodule_fit_rms`。
- 验收：从已知半径的球面上截取一小块并加噪声，能恢复出半径。

### 3.3 上下体积切分 ✅ 2026-10-18

> 完成：按闭合曲线（沿网格边链分两侧，曲线点中心扇形封口）或拟合平面（剖开封口）切分封闭模型，上侧 = 法向一侧（可互换）；两侧之和等于总体积（测试核对）；测量 CSV 增加三列。

- **切分依据**二选一：一条闭合曲线（如石核边缘），或一个拟合平面。
  - 闭合曲线：沿其网格边链把表面分成两侧；以曲线点的中心为顶点做扇形封口面；分别计算两侧体积。
  - 平面：用平面剖开模型，把剖面多边形三角化后封口，分别计算两侧体积。
- 两侧体积之和应等于总体积，测试中检查。
- 「上」侧 = 法向所指的一侧。用平面时取该平面的法向；用曲线时取该曲线拟合平面的法向，朝向规则同 1.2。
- 只对封闭模型可用。
- 导出：`_measurements.csv` 增加 `volume_upper, volume_lower, volume_ratio`（上 / 下）。
- 验收：立方体沿中面切分，两侧各占一半；斜切面与解析值一致。

## 阶段 4　片疤关系与地标

### 4.1 打破关系与剥片序列 ✅ 2026-10-18

> 完成：关系工具（B）点两个片疤记录关系，序列与片疤归属，四项实时检查及高亮，Harris 矩阵面板（SVG 导出），按序列配色，relations / series 两个 CSV。

- **关系**：选两个片疤（点箭头或区域），记录「A 打破 B」（A 晚于 B）、「B 打破 A」或「无法判断」。「无法判断」要明确保存，以区别于「还没判断」。
- **序列**：可以新建剥片序列并排定先后，把片疤归入序列；序列内部可排先后。
- **实时检查**：
  1. 打破关系是否成环；
  2. 关系与序列先后是否矛盾；
  3. 关系与序列内部的先后是否矛盾；
  4. 是否有片疤未归入序列（仅作提示）。

  问题以计数标记显示；点开后列出明细，并在三维中高亮涉及的片疤。
- **Harris 矩阵（实时）**：可开关的面板，随标注实时更新。
  - 节点 = 片疤，按序列分组框起，晚的在上、早的在下；
  - 只画直接关系（做传递约简），「无法判断」不画线，成环的边标红；
  - 点击节点 ↔ 选中三维中对应的片疤；
  - 可导出 SVG。
- **三维着色**：按序列配色，序列内由浅到深表示先后。没有区域时给箭头上色，有区域时给区域填色。
- **导出**：
  - `<标本>_relations.csv`：`specimen_id, scar_a, scar_b, relation`（`a_cuts_b` / `indeterminate`）
  - `<标本>_series.csv`：`specimen_id, series_id, series_order, scar_id, order_in_series`
- **验收**：成环与矛盾检测的单元测试；增删关系后矩阵布局随之更新；撤销正确。

## 阶段 5　一致性与批量

### 5.1 观察者间一致性（比较模式） ✅ 2026-10-18

> 完成：比较模式载入同一模型的多个项目文件、按标注者着色叠加；箭头 / 曲线匈牙利配对，平面、区域、地标、半地标、属性、关系、测量逐类比较（Cohen / Fleiss κ、IoU、Dice、距离、差值）；导出长格式明细与汇总表。ICC 已实现（`icc21`），多件标本的 ICC 随 5.2 批量汇总输出。

- 载入同一模型（SHA-256 一致）的多个项目文件；每个文件代表一位标注者，或同一人的一次重复标注。
- **覆盖全部标注与测量**，各类的配对方式与指标：
  - 片疤箭头：按起点、终点距离做最优配对（匈牙利算法）；指标为方向夹角、起点距离、终点距离，以及未配对数。
  - 片疤属性、区域类型、打破关系：一致率；两人用 Cohen's κ，多人用 Fleiss' κ。
  - 曲线：按类型和距离配对；指标为平均对称距离、Hausdorff 距离。
  - 拟合平面：按方法配对；指标为法向夹角、中心距离。
  - 区域：同类型面片集合的 IoU 和 Dice；片疤区域按最大重叠配对。
  - 地标：按名称配对，看欧氏距离；半地标按组和序号配对。
  - 测量值（自动和手动）：看差值；多件标本时计算 ICC。
- **叠加显示**：不同标注者用不同颜色。
- **导出**：长格式表 `specimen_id, item_type, item_key, annotator_a, annotator_b, metric, value`，以及一份汇总表。正式统计可在 R 中进行。

### 5.2 批量处理 ✅ 2026-10-18

## 阶段 6　体验优化（整阶段一次做完）

用户试用后确定（2026-10-17）。**本阶段例外**：

- 一次会话、一个分支或 PR，连续做完 6.1–6.14，中途不停下。
- 不逐项验收：不为本阶段新写测试，也不逐项做浏览器验证。全部做完后由用户自己先看，需要时再另开一轮验收。
- 仍要求 `npm test`、`npm run build` 通过。现有 e2e 如果只是因为控件挪了位置而失败，就更新选择器，使 CI 保持通过；不要为了通过测试改变本阶段要求的行为。
- 全部做完后，在每项后面标 ✅ 和日期；交付说明逐项写改了什么，并列出待确认事项。
- 不改项目文件格式，也不改导出文件的文件名和列。

### 6.1 侧栏：工具联动与空内容 ⬜

- **工具联动**：切换工具时，侧栏只展开该工具对应的分区，其余折叠：
  - 标注模式：画箭头 → 片疤箭头，画曲线 → 曲线，区域 → 表面区域，关系 → 打破关系与序列，地标 → 地标；
  - 测量模式：距离、沿表面、角度 → 手动测量；
  - 展示模式：截面 → 截面。

  切换到「选择」工具时不改变展开状态。手动展开、折叠仍照常记住（现有的 `sec:<id>` 偏好）；联动只在切换工具时发生。
- **选中对象时**：展开它所在的分区，并把它的检查面板滚到侧栏可见区域的顶部。
- **空分区**：只保留标题行（带计数 0）和创建入口（如「添加平面」「新建序列」），不显示空列表和不可用的控件。
- **前提不满足的分区整个不显示**：没有石皮区域时不显示「石皮拟合球」；既没有闭合曲线也没有平面时不显示「上下体积」。
- **区域汇总**只列面积不为 0 的类型；石皮比只在有石皮时显示。
- **没打开模型时**，侧栏只显示打开入口。

### 6.2 顶栏：标本信息与文件菜单 ⬜

- **标本信息移到顶栏**：一行显示标本编号（可直接编辑）和坐标单位（下拉）。点击后展开一个小面板，可编辑标注者、备注，并查看模型文件名和面片数。四个模式的侧栏都去掉「标本」分区。
- **文件菜单**：「打开模型」「打开项目」「打开文件夹」合并成一个「文件」下拉菜单；「保存」单独保留为按钮。
- **模式切换**（标注 / 测量 / 展示 / 比较）放大，放在顶栏中间，是顶栏里最醒目的控件。
- **主色按钮**：未打开模型时是「文件」；打开模型后改为「保存」。
- **窗口变窄、按钮只剩图标时**，每个图标都要能区分；不能再出现两个相同的文件夹图标。

### 6.3 显示设置移到视口 ⬜

- 视口右上角加一个「显示」按钮，点开浮动面板，内容就是现在侧栏里的「显示」分区（着色、曲率尺度、光照、背景、箭头粗细和颜色、编号等）。点面板外或按 Esc 关闭。
- 四个模式的侧栏都去掉「显示」分区。

### 6.4 导出合并 ⬜

- 每个模式侧栏里的数据导出按钮（各类 CSV、地标 TPS / .fcsv、滑动定义、一致性明细与汇总等）合并成一个「导出」按钮，使用次要样式。
- 点开后是一个对话框，列出当前模式可导出的文件：
  - 每个文件一个勾选框，默认勾选有数据的；没有数据的不可选；
  - 点一次导出全部所选文件。
- 选了多个文件时打包成一个 zip（`<标本>_export.zip`）：可以自写不压缩的 zip，也可以用 fflate（MIT）；只选一个文件时直接下载。下载仍通过现有的 `io/saveFile.ts`（claude.ai 中走 downloads 能力）。
- 文件名和列都不变。
- 展示模式的出图按钮（PNG / SVG）和截面导出保持原样，不并入此对话框。
- 保存项目、打开项目只在顶栏的文件菜单和保存按钮里。

### 6.5 侧栏宽度可调 ⬜

- 拖动侧栏左边缘调整宽度（约 300–640 px），宽度记在偏好里。

### 6.6 Harris 矩阵面板 ⬜

- 拖动标题栏可以移动，拖右下角可以调大小，点标题栏按钮可以折叠成一行；位置、大小和折叠状态都记在偏好里。
- 面板的层级高于三维里的编号标签（CSS2D 标签层），标签不能再画到面板上面。
- 没有任何「打破」关系的片疤（包括只有「无法判断」关系的）不放进主图，单独放在面板一侧的「无关系」一栏。

### 6.7 编号标签避让 ⬜

- 视口里的编号标签（片疤、曲线、地标、测量、平面、截面）重叠时自动错开：在屏幕空间里按优先级处理，选中项最高，被挡住的标签向外偏移；偏移后仍重叠的，隐藏优先级较低的那个。
- 比较模式只显示当前项目的编号，其他标注者的编号不显示。

### 6.8 各模式的默认图层 ⬜

- **测量模式**：标注层（箭头、编号、曲线、区域着色、地标）调淡显示；测量相关的内容（手动测量、平面、拟合球、体积切分）正常显示。
- **展示模式**：视口里不显示编号标签；各叠加层按「出图」里的开关显示或隐藏，出图里关掉的层，视口里也不显示。
- 比较模式维持现状（各标注者用自己的颜色）。

### 6.9 拟合平面圆盘 ⬜

- 圆盘默认透明度极高，几乎看不见（不透明度约为现在的五分之一）；选中某个平面时，它的圆盘恢复现在的透明度。
- 圆盘大小、平面与表面的交线、法向箭头都不变。

### 6.10 区域着色 ⬜

- 视口里的区域着色要让片疤起伏清楚可见：降低不透明度，或改用能透出底下明暗的混合方式。出图不受影响。

### 6.11 打破关系的选择方式 ⬜

- 点第二个片疤后，不再弹出屏幕中央的对话框，改为在点击处旁边出现一个小浮层，选项与现在相同。
- 键盘：1 = 「A 打破 B」，2 = 「B 打破 A」，3 = 「无法判断」，Delete = 删除已有关系（仅在已有关系时出现），Esc = 取消。
- 浮层不能遮住刚点的两个片疤；靠近视口边缘时自动换到另一侧。

### 6.12 一致性表 ⬜

- 侧栏里的表按对象分组：片疤箭头、片疤属性、曲线、平面、区域、地标、半地标、关系、测量……
- 每组第一行写配对情况，例如「配对 8 / 8 · A 未配对 0 · B 未配对 0」。之后每行一个指标：中文名、数值、单位（°、mm、mm² 等）；计数不再放进「均值」列。英文界面用英文名。
- 点击一行：三维中高亮该指标差异最大的那一对。
- 导出的 CSV 不变，仍用代码名。

### 6.13 字体打包进 HTML ⬜

- 继续用现在的 IBM Plex Sans、IBM Plex Sans Condensed、IBM Plex Mono，只取界面用到的字重和拉丁字符子集，打包进单个 HTML，不再请求 Google Fonts。可以用 `@fontsource` 的包，也可以把 woff2 文件放进仓库。IBM Plex 是 SIL OFL 1.1 许可，允许随软件打包，用户已同意。
- 删除 `index.html` 里 fonts.googleapis.com 和 fonts.gstatic.com 的 preconnect 和样式表链接。
- 中文仍用系统字体。HTML 体积的增加控制在约 200 KB 以内。

### 6.14 快捷键对话框与标注者提示 ⬜

- 「?」对话框里的快捷键按「通用 / 标注 / 测量 / 展示」分组。
- 保存项目时如果标注者为空，给一个轻提示（toast），提醒一致性分析要靠它区分人；不阻止保存。
