### 0.2 数据模型 v2 ✅ 2026-10-17

> 完成：片疤成为独立对象（`annotations.scars`，箭头为可选的 `vector`），新增 `specimen.frame` 与 `derived`；`formatVersion` 2，v1 文件读入时自动迁移，箭头 CSV 不变。

- 箭头 CSV 的列不变，只输出有 `vector` 的片疤。
- 更新 `docs/project-format.md`（改写为 v2，并列出与 v1 的差异）。
- 验收：v1 文件（含曲线和不含曲线）读入 → 保存 → 再读入，内容一致；现有功能全部不变。

## 阶段 1　测量与平面

### 1.1 基础测量（测量模式） ✅ 2026-10-17

> 完成：打开模型即分帧计算长宽厚、表面积、体积（仅封闭）、Surface-to-Volume Ratio、Wadell 球度；手动测量直线 / 沿表面 / 角度（M1…，可撤销，存入项目文件）；两种 CSV。

**自动测量**（打开模型即算，显示在测量模式侧栏）：

- 长、宽、厚：模型在三个轴上的投影范围。有标本坐标系时用它（Y 长、X 宽、Z 厚）；没有时用面积加权主轴（第一主轴为长）。记录用的是哪种（`frame` = `specimen` / `principal`）。
- 表面积 A。
- 体积 V：只在模型封闭时计算。不封闭时显示「未封闭」，体积相关的值留空，不自动补洞。
- **Surface-to-Volume Ratio** = A / V^(2/3)，无量纲。中英文界面都用这个名称，CSV 列名 `surface_to_volume_ratio`。
- Wadell 球度 ψ = π^(1/3)·(6V)^(2/3) / A，CSV 列名 `wadell_sphericity`。

**手动测量**（作为标注保存，可撤销，列表编号 M1、M2……）：

- 两点直线距离；
- 两点沿表面距离：用现有 `PathSearch`（吸附关闭）连接两点，再用 `relaxPath` 拉紧，显示路径；
- 三点角度：中间的点为顶点，单位为度。

**导出**：

- `<标本>_measurements.csv`，每件一行：`specimen_id, unit, frame, length, width, thickness, surface_area, volume, surface_to_volume_ratio, wadell_sphericity, closed`
- `<标本>_manual_measurements.csv`，每条一行：`specimen_id, measure_id, type (distance / geodesic / angle), value, unit, p1_x … p3_z`（用不到的点留空；角度的 unit 为 `deg`）

**验收**：立方体、球的已知值；不封闭模型的体积留空；手动测量的撤销、重做、保存往返。

### 1.2 拟合平面 ⬜

四种方法（代码 / 定义）：

1. `all_vertices`（Lin et al. 2024）：对模型全部顶点做最小二乘平面，不加权，与 Geomagic「Best Fit」选全部点的做法一致。中心 = 全部顶点的均值。
2. `scar_directions`（Xiao et al. 2026）：全部片疤方向的单位向量，不加权；方向张量 T = Σ u·uᵀ，法向 = T 最小特征值对应的特征向量（即与所有片疤方向最平行的平面）。中心 = 全部片疤中点（起点与终点的中点）的均值。
3. `scar_starts`：片疤起点的最小二乘平面。可按完整性类型筛选：默认全部选中，使用者可以排除任意类型（例如 `both_missing`）。点几乎共线时不提示。中心 = 所用起点的均值。
4. `curves`：一条或多条曲线，开放或闭合都可以。先按等弧长重新取点，再做最小二乘平面。中心 = 重新取点后的均值。

其他规则：

- 输入不足时平面无效：少于 3 个点，或 `scar_directions` 少于 2 个不平行的方向。界面显示为无效状态。
- **法向朝向**：创建时默认指向当前观察者，记录为 `upHint`；法向始终取与 `upHint` 同侧。「翻转」即把 `upHint` 取反。
- 平面是派生对象：所用片疤、曲线或筛选条件变化时自动重算。
- **平面坐标系**（用于变换矩阵）：原点 = 中心；+Z = 法向；+X = 模型第一主轴（全部顶点 PCA）在平面上的投影，单位化，符号取使其绝对值最大的分量为正；+Y = Z × X。若第一主轴与法向几乎平行，改用第二主轴。

可视化：

- 半透明圆盘（半径覆盖模型在平面上的投影）、平面与模型表面的交线、法向箭头。
- 每个平面一种颜色，可单独显示或隐藏。
- 「沿法向观察」把视角转到垂直于平面。

侧栏：平面列表（P1、P2……）；检查面板只有方法、输入（曲线选择 / 完整性筛选）、翻转、沿法向观察、删除。

导出 `<标本>_planes.csv`，只含：`specimen_id, plane_id, method, center_x, center_y, center_z, normal_x, normal_y, normal_z, m00 … m33`。其中 m 为 4×4 变换矩阵，行主序，把原始坐标变换到平面坐标系。

验收：

- 已知平面上的点；已知环带分布的方向；倾斜圆周上的曲线，其中只取一段开放的弧也能恢复平面；
- 矩阵把中心映到原点、法向映到 +Z；
- 输入变化后平面更新；撤销正确。

## 阶段 2　展示模式

### 2.1 标本定向 ⬜

- 在展示模式中设置 `specimen.frame`：
  - 正视方向 = 所选平面的法向，或当前视角；
  - 图面内旋转：±90° 按钮加拖动微调；
  - 可选「以某个箭头定纵轴」。
- 只记录矩阵，模型不动，相机按矩阵摆放。
- 默认按欧洲惯例：石片和石叶近端（台面）朝下、背面为正视面；石核的正视面和朝向由使用者决定。

### 2.2 标准正投影视图与出图 ⬜

- **视图**：正面、背面、左、右、上、下，可任选几个。
- **排版：欧洲惯例（ISO 第一角投影）**
  - 从左侧看到的视图放在正视图右侧，从右侧看到的放在左侧；
  - 从上看到的放在正视图下方，从下看到的放在上方；
  - 背面放在最右侧（左视图的右边）；
  - 所有视图比例相同、相互对齐。
- **光照**：掠射光，默认来自图面左上方（石器线图惯例），高度角可调。
- **叠加层**逐项开关：片疤箭头、曲线、平面交线、地标、区域着色、比例尺。
- **比例尺**：公制，水平线带刻度（例如每 10 mm 一大格），单位取自 `specimen.unit`。单位未注明时不可用。
- **PNG**：透明背景；按实物比例（默认 1:1，可选 2:1、1:2）和 dpi（300 / 600 / 1200）输出。
- **SVG**：模型明暗作为内嵌位图；箭头、曲线、平面交线、地标、比例尺和外轮廓为矢量，被模型遮挡的部分不画；尺寸以 mm 为单位。
- 验收：
  - 导出图里比例尺的像素长度与实物比例一致（测试中按像素核对）；
  - 背景透明；
  - SVG 结构合法，Inkscape 能打开。

### 2.3 截面（仅用于展示） ⬜

- 在展示模式中，在屏幕上画一条直线穿过模型；切面由这条直线和视线方向确定。
- **显示**：三维视图中按切面剖开模型（可选保留哪一侧），剖面用平涂或斜线填充；截面轮廓也可作为叠加层显示。
- **导出**：截面轮廓 SVG / PNG（矢量轮廓加比例尺）；也可以加进 2.2 的图版，默认放在整组视图的右侧。
- 不输出任何测量值。

## 阶段 3　表面区域

### 3.1 曲线网络自动分区 ⬜

- **曲线工具增强**：曲线端点可以吸附到已有曲线上，形成 T 形交接，这样几条曲线能围成封闭区域。
- **分区**：
  - 把每条曲线换算成一串网格边：曲线点就近取顶点，相邻顶点之间用最短路相连。
  - 以这些网格边为界，对面片做连通分区，每个连通块是一个候选区域。
  - 曲线变化时自动重算。
- **类型**：`scar` 片疤（人工改造）、`cortex` 石皮、`joint` 节理面（未改造）、`damage` 破损。点击候选区域后选类型（数字键 1–4）。
- **保存方式**：区域保存为「种子点」，即点击处的表面坐标、类型和片疤 id。重算后，包含种子点的连通块继承类型；两个种子落进同一块时提示冲突。
- **与片疤对象关联**：区域内有箭头起点时，自动关联该片疤；没有时新建一个无方向的片疤。
- **显示**：按类型半透明着色（片疤区域可按片疤区分），可开关。
- **计算**：各区域面积、各类型总面积、石皮比 = 石皮面积 / 总表面积。
- **导出**：
  - `<标本>_regions.csv`：`specimen_id, region_id, type, scar_id, area, unit`
  - `_measurements.csv` 增加：`area_scar, area_cortex, area_joint, area_damage, cortex_ratio`
- **验收**：在合成模型上用曲线围出已知区域，面积与解析值之差在网格分辨率允许的范围内；曲线修改后区域类型保持不变。

### 3.2 石皮拟合球 ⬜

- 对选定的石皮区域（默认全部）做球面最小二乘拟合：先用代数解求初值，再做几何迭代精化。输出半径、球心、残差 RMS。三维中可显示拟合球（线框）。
- 导出：`_measurements.csv` 增加 `nodule_radius, nodule_fit_rms`。
- 验收：从已知半径的球面上截取一小块并加噪声，能恢复出半径。

### 3.3 上下体积切分 ⬜

- **切分依据**二选一：一条闭合曲线（如石核边缘），或一个拟合平面。
  - 闭合曲线：沿其网格边链把表面分成两侧；以曲线点的中心为顶点做扇形封口面；分别计算两侧体积。
  - 平面：用平面剖开模型，把剖面多边形三角化后封口，分别计算两侧体积。
- 两侧体积之和应等于总体积，测试中检查。
- 「上」侧 = 法向所指的一侧。用平面时取该平面的法向；用曲线时取该曲线拟合平面的法向，朝向规则同 1.2。
- 只对封闭模型可用。
- 导出：`_measurements.csv` 增加 `volume_upper, volume_lower, volume_ratio`（上 / 下）。
- 验收：立方体沿中面切分，两侧各占一半；斜切面与解析值一致。

## 阶段 4　片疤关系与地标

### 4.1 打破关系与剥片序列 ⬜

- **关系**：选两个片疤（点箭头或区域），记录「A 打破 B」（A 晚于 B）、「B 打破 A」或「无法判断」。「无法判断」要明确保存，以区别于「还没判断」。
- **序列**：可以新建剥片序列并排定先后，把片疤归入序列；序列内部可排先后。
- **实时检查**：
  1. 打破关系是否成环；
  2. 关系与序列先后是否矛盾；
  3. 关系与序列内部的先后是否矛盾；
  4. 是否有片疤未归入序列（仅作提示）。

  问题以计数标记显示；点开后列出明细，并在三维中高亮涉及的片疤。
- **Harris 矩阵（实时）**：可开关的面板，随标注实时更新。
  - 节点 = 片疤，按序列分组框起，晚的在上、早的在下；
  - 只画直接关系（做传递约简），「无法判断」不画线，成环的边标红；
  - 点击节点 ↔ 选中三维中对应的片疤；
  - 可导出 SVG。
- **三维着色**：按序列配色，序列内由浅到深表示先后。没有区域时给箭头上色，有区域时给区域填色。
- **导出**：
  - `<标本>_relations.csv`：`specimen_id, scar_a, scar_b, relation`（`a_cuts_b` / `indeterminate`）
  - `<标本>_series.csv`：`specimen_id, series_id, series_order, scar_id, order_in_series`
- **验收**：成环与矛盾检测的单元测试；增删关系后矩阵布局随之更新；撤销正确。

### 4.2 地标 ⬜

- **固定地标**：在表面上点选，可选吸附到棱脊；每个点自由输入名称或含义；列表顺序即导出顺序，可拖动调整。
- **「沿用上一件的点名列表」**（可选）：载入上一件标本的点名顺序，之后点选时依次套用这些名称，可跳过。
- **曲线半地标**：选一条曲线和点数 N，可指定起止固定地标；沿曲线等弧长取点；曲线修改后自动更新。
- **滑动**在 R 中完成（`geomorph::gpagen` / `Morpho::procSym`），软件只导出滑动定义。
- **导出**：
  - TPS（LM3）；
  - Slicer `.fcsv`；
  - 长格式 CSV：`specimen_id, index, name, kind (fixed / curve), set_id, x, y, z`；
  - 滑动定义 CSV：geomorph `curves` 格式，三列 before, slider, after，用导出点的序号表示。

  点的顺序：先固定地标（按列表顺序），再按组列出各组半地标。
- **验收**：等弧长取点和滑动定义的单元测试；TPS 和 `.fcsv` 格式正确。

## 阶段 5　一致性与批量

### 5.1 观察者间一致性（比较模式） ⬜

- 载入同一模型（SHA-256 一致）的多个项目文件；每个文件代表一位标注者，或同一人的一次重复标注。
- **覆盖全部标注与测量**，各类的配对方式与指标：
  - 片疤箭头：按起点、终点距离做最优配对（匈牙利算法）；指标为方向夹角、起点距离、终点距离，以及未配对数。
  - 片疤属性、区域类型、打破关系：一致率；两人用 Cohen's κ，多人用 Fleiss' κ。
  - 曲线：按类型和距离配对；指标为平均对称距离、Hausdorff 距离。
  - 拟合平面：按方法配对；指标为法向夹角、中心距离。
  - 区域：同类型面片集合的 IoU 和 Dice；片疤区域按最大重叠配对。
  - 地标：按名称配对，看欧氏距离；半地标按组和序号配对。
  - 测量值（自动和手动）：看差值；多件标本时计算 ICC。
- **叠加显示**：不同标注者用不同颜色。
- **导出**：长格式表 `specimen_id, item_type, item_key, annotator_a, annotator_b, metric, value`，以及一份汇总表。正式统计可在 R 中进行。

### 5.2 批量处理 ⬜

- **工作区**：打开一个文件夹（模型加项目文件），可上一件、下一件切换，项目文件自动保存在模型旁边。Chrome / Edge 用 File System Access API；其他浏览器只能读，保存需逐个下载。
- **批量计算**：对文件夹内全部模型计算 1.1 的自动测量，并汇总已有项目文件中的派生指标，每件一行。
- **批量出图**：用同一套展示设置，导出全部标本的标准视图。
- 一件一件处理，处理完释放内存；显示进度，可以取消。
- 所有 CSV 按类型各合并成一份。
