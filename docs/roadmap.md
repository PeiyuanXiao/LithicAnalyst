### 0.2 数据模型 v2 ✅ 2026-10-17

> 完成：片疤成为独立对象（`annotations.scars`，箭头为可选的 `vector`），新增 `specimen.frame` 与 `derived`；`formatVersion` 2，v1 文件读入时自动迁移，箭头 CSV 不变。

- 箭头 CSV 的列不变，只输出有 `vector` 的片疤。
- 更新 `docs/project-format.md`（改写为 v2，并列出与 v1 的差异）。

## 阶段 1　测量与平面

### 1.1 基础测量（测量模式） ✅ 2026-10-17

> 完成：打开模型即分帧计算长宽厚、表面积、体积（仅封闭）；手动测量直线 / 沿表面 / 角度（M1…，可撤销，存入项目文件）；两种 CSV。

**自动测量**（打开模型即算，显示在测量模式侧栏）：

- 长、宽、厚：模型在三个轴上的投影范围。有标本坐标系时用它（Y 长、X 宽、Z 厚）；没有时用面积加权主轴（第一主轴为长）。记录用的是哪种（`frame` = `specimen` / `principal`）。
- 表面积 A。
- 体积 V：只在模型封闭时计算。不封闭时显示「未封闭」，体积相关的值留空，不自动补洞。
- Surface-to-Volume Ratio 和 Wadell 球度：已在 15.1 删除。

**手动测量**（作为标注保存，可撤销，列表编号 M1、M2……）：

- 两点直线距离；
- 两点沿表面距离：用现有 `PathSearch`（吸附关闭）连接两点，再用 `relaxPath` 拉紧，显示路径；
- 三点角度：中间的点为顶点，单位为度。

**导出**：

- `<标本>_measurements.csv`，每件一行：`specimen_id, unit, frame, length, width, thickness, surface_area, volume, closed`（9.8 起末尾另有 `file`：模型文件，文件夹中为相对路径）
- `<标本>_manual_measurements.csv`，每条一行：`specimen_id, measure_id, type (distance / geodesic / angle), value, unit, p1_x … p3_z`（用不到的点留空；角度的 unit 为 `deg`）

**验收**：立方体、球的已知值；不封闭模型的体积留空；手动测量的撤销、重做、保存往返。

### 1.2 拟合平面 ✅ 2026-10-17

> 完成：四种方法、法向按 upHint 定向（可翻转）、平面坐标系矩阵；输入变化即重算；圆盘 + 交线 + 法向箭头，逐个显示 / 隐藏、沿法向观察；平面 CSV。

四种方法（代码 / 定义）：

1. `all_vertices`（Lin et al. 2024）：对模型全部顶点做最小二乘平面，不加权，与 Geomagic「Best Fit」选全部点的做法一致。中心 = 全部顶点的均值。
2. `scar_directions`（Xiao et al. 2026）：全部片疤方向的单位向量，不加权；方向张量 T = Σ u·uᵀ，法向 = T 最小特征值对应的特征向量（即与所有片疤方向最平行的平面）。中心 = 全部片疤中点（起点与终点的中点）的均值。
3. `scar_starts`：片疤起点的最小二乘平面。可按完整性类型筛选：默认全部选中，使用者可以排除任意类型（例如 `both_missing`）。点几乎共线时不提示。中心 = 所用起点的均值。
4. `curves`：一条或多条曲线，开放或闭合都可以。先按等弧长重新取点，再做最小二乘平面。中心 = 重新取点后的均值。

其他规则：

- 输入不足时平面无效：少于 3 个点，或 `scar_directions` 少于 2 个不平行的方向。界面显示为无效状态。
- **法向朝向**：创建时默认指向当前观察者，记录为 `upHint`；法向始终取与 `upHint` 同侧。「翻转」即把 `upHint` 取反。
- 平面是派生对象：所用片疤、曲线或筛选条件变化时自动重算。
- **平面坐标系**（用于变换矩阵）：原点 = 中心；+Z = 法向；+X = 模型第一主轴（全部顶点 PCA）在平面上的投影，单位化，符号取使其绝对值最大的分量为正；+Y = Z × X。若第一主轴与法向几乎平行，改用第二主轴。

可视化：

- 半透明圆盘（半径覆盖模型在平面上的投影）、平面与模型表面的交线、法向箭头。
- 每个平面一种颜色，可单独显示或隐藏。
- 「沿法向观察」把视角转到垂直于平面。

侧栏：平面列表（P1、P2……）；检查面板只有方法、输入（曲线选择 / 完整性筛选）、翻转、沿法向观察、删除。

导出 `<标本>_planes.csv`，只含：`specimen_id, plane_id, method, center_x, center_y, center_z, normal_x, normal_y, normal_z, m00 … m33`。其中 m 为 4×4 变换矩阵，行主序，把原始坐标变换到平面坐标系。

验收：

- 已知平面上的点；已知环带分布的方向；倾斜圆周上的曲线，其中只取一段开放的弧也能恢复平面；
- 矩阵把中心映到原点、法向映到 +Z；
- 输入变化后平面更新；撤销正确。

## 阶段 2　展示模式

### 2.1 标本定向 ✅ 2026-10-17

> 完成：展示模式里以当前视角或平面法向为正视、箭头定纵轴、±90° 与微调；只记录矩阵，相机按矩阵摆放；长宽厚随之按标本坐标系计算。

- 在展示模式中设置 `specimen.frame`：
  - 正视方向 = 所选平面的法向，或当前视角；
  - 图面内旋转：±90° 按钮加拖动微调；
  - 可选「以某个箭头定纵轴」。
- 只记录矩阵，模型不动，相机按矩阵摆放。
- 默认按欧洲惯例：石片和石叶近端（台面）朝下、背面为正视面；石核的正视面和朝向由使用者决定。

### 2.2 标准正投影视图与出图 ✅ 2026-10-17

> 完成：六个视图任选、第一角投影排版；左上方掠射光；叠加层开关；PNG（透明、实物比例、dpi 写入文件）与 SVG（mm、矢量叠加与外轮廓、遮挡部分不画）。比例尺像素长度、背景透明、SVG 结构在测试中核对。

- **视图**：正面、背面、左、右、上、下，可任选几个。
- **排版：欧洲惯例（ISO 第一角投影）**
  - 从左侧看到的视图放在正视图右侧，从右侧看到的放在左侧；
  - 从上看到的放在正视图下方，从下看到的放在上方；
  - 背面放在最右侧（左视图的右边）；
  - 所有视图比例相同、相互对齐。
- **光照**：掠射光，默认来自图面左上方（石器线图惯例），高度角可调。
- **叠加层**逐项开关：片疤箭头、曲线、平面交线、地标、区域着色、比例尺。
- **比例尺**：公制，水平线带刻度（例如每 10 mm 一大格），单位取自 `specimen.unit`。单位未注明时不可用。
- **PNG**：透明背景；按实物比例（默认 1:1，可选 2:1、1:2）和 dpi（300 / 600 / 1200）输出。
- **SVG**：模型明暗作为内嵌位图；箭头、曲线、平面交线、地标、比例尺和外轮廓为矢量，被模型遮挡的部分不画；尺寸以 mm 为单位。
- 验收：
  - 导出图里比例尺的像素长度与实物比例一致（测试中按像素核对）；
  - 背景透明；
  - SVG 结构合法，Inkscape 能打开。

### 2.3 截面（仅用于展示） ✅ 2026-10-17

> 完成：展示模式拖线定截面（直线 + 视线方向）；三维中可保留一侧，剖面平涂 / 斜线；截面图单独导出 SVG / PNG 或加进图版右侧；不输出测量值。

- 在展示模式中，在屏幕上画一条直线穿过模型；切面由这条直线和视线方向确定。
- **显示**：三维视图中按切面剖开模型（可选保留哪一侧），剖面用平涂或斜线填充；截面轮廓也可作为叠加层显示。
- **导出**：截面轮廓 SVG / PNG（矢量轮廓加比例尺）；也可以加进 2.2 的图版，默认放在整组视图的右侧。
- 不输出任何测量值。

## 阶段 3　表面区域

### 3.1 曲线网络自动分区 ✅ 2026-10-18

> 完成：曲线端点吸附已有曲线；曲线→网格边链→连通分区，曲线变化即重算；种子点定类型（1–4），关联片疤或新建无方向片疤，冲突提示；着色、面积、各类型总面积与石皮比；区域 CSV 与测量 CSV 新列。

- **曲线工具增强**：曲线端点可以吸附到已有曲线上，形成 T 形交接，这样几条曲线能围成封闭区域。
- **分区**：
  - 把每条曲线换算成一串网格边：曲线点就近取顶点，相邻顶点之间用最短路相连。
  - 以这些网格边为界，对面片做连通分区，每个连通块是一个候选区域。
  - 曲线变化时自动重算。
- **类型**：`scar` 片疤（人工改造）、`cortex` 石皮、`joint` 节理面（未改造）、`damage` 破损。点击候选区域后选类型（数字键 1–4）。
- **保存方式**：区域保存为「种子点」，即点击处的表面坐标、类型和片疤 id。重算后，包含种子点的连通块继承类型；两个种子落进同一块时提示冲突。
- **与片疤对象关联**：区域内有箭头起点时，自动关联该片疤；没有时新建一个无方向的片疤。
- **显示**：按类型半透明着色（片疤区域可按片疤区分），可开关。
- **计算**：各区域面积、各类型总面积、石皮比 = 石皮面积 / 总表面积。
- **导出**：
  - `<标本>_regions.csv`：`specimen_id, region_id, type, scar_id, area, unit`
  - `_measurements.csv` 增加：`area_scar, area_cortex, area_joint, area_damage, cortex_ratio`
- **验收**：在合成模型上用曲线围出已知区域，面积与解析值之差在网格分辨率允许的范围内；曲线修改后区域类型保持不变。

### 3.2 石皮拟合球 ✅ 2026-10-18

> 完成：选定石皮区域（默认全部）的顶点做代数初值 + 几何迭代的球面拟合，给出半径、球心、残差 RMS，可显示线框球；测量 CSV 增加 `nodule_radius, nodule_fit_rms`。

- 对选定的石皮区域（默认全部）做球面最小二乘拟合：先用代数解求初值，再做几何迭代精化。输出半径、球心、残差 RMS。三维中可显示拟合球（线框）。
- 导出：`_measurements.csv` 增加 `nodule_radius, nodule_fit_rms`。
- 验收：从已知半径的球面上截取一小块并加噪声，能恢复出半径。

### 3.3 上下体积切分 ✅ 2026-10-18

> 完成：按闭合曲线（沿网格边链分两侧，曲线点中心扇形封口）或拟合平面（剖开封口）切分封闭模型，上侧 = 法向一侧（可互换）；两侧之和等于总体积（测试核对）；测量 CSV 增加三列。

- **切分依据**二选一：一条闭合曲线（如石核边缘），或一个拟合平面。
  - 闭合曲线：沿其网格边链把表面分成两侧；以曲线点的中心为顶点做扇形封口面；分别计算两侧体积。
  - 平面：用平面剖开模型，把剖面多边形三角化后封口，分别计算两侧体积。
- 两侧体积之和应等于总体积，测试中检查。
- 「上」侧 = 法向所指的一侧。用平面时取该平面的法向；用曲线时取该曲线拟合平面的法向，朝向规则同 1.2。
- 只对封闭模型可用。
- 导出：`_measurements.csv` 增加 `volume_upper, volume_lower, volume_ratio`（上 / 下）。
- 验收：立方体沿中面切分，两侧各占一半；斜切面与解析值一致。

## 阶段 4　片疤关系与地标

### 4.1 打破关系与剥片序列 ✅ 2026-10-18

> 完成：关系工具（B）点两个片疤记录关系，序列与片疤归属，四项实时检查及高亮，Harris 矩阵面板（SVG 导出），按序列配色，relations / series 两个 CSV。

- **关系**：选两个片疤（点箭头或区域），记录「A 打破 B」（A 晚于 B）、「B 打破 A」或「无法判断」。「无法判断」要明确保存，以区别于「还没判断」。
- **序列**：可以新建剥片序列并排定先后，把片疤归入序列；序列内部可排先后。
- **实时检查**：
  1. 打破关系是否成环；
  2. 关系与序列先后是否矛盾；
  3. 关系与序列内部的先后是否矛盾；
  4. 是否有片疤未归入序列（仅作提示）。

  问题以计数标记显示；点开后列出明细，并在三维中高亮涉及的片疤。
- **Harris 矩阵（实时）**：可开关的面板，随标注实时更新。
  - 节点 = 片疤，按序列分组框起，晚的在上、早的在下；
  - 只画直接关系（做传递约简），「无法判断」不画线，成环的边标红；
  - 点击节点 ↔ 选中三维中对应的片疤；
  - 可导出 SVG。
- **三维着色**：按序列配色，序列内由浅到深表示先后。没有区域时给箭头上色，有区域时给区域填色。
- **导出**：
  - `<标本>_relations.csv`：`specimen_id, scar_a, scar_b, relation`（`a_cuts_b` / `indeterminate`）
  - `<标本>_series.csv`：`specimen_id, series_id, series_order, scar_id, order_in_series`
- **验收**：成环与矛盾检测的单元测试；增删关系后矩阵布局随之更新；撤销正确。

### 10.4 七项构型的判定 ✅ 2026-10-30

> 完成：computeConfiguration 给出七项，阈值为具名常量并随结果保存；9 组已知答案的单元测试。

**用到的台面**：剥片面上所有片疤的台面，只算角色为 `platform` / `both` 的面。**台面面**：角色为 `platform` / `both` 的所有面。

1. **面性** `facial_character`：剥片面 1 个 `unifacial` 单面 / Unifacial；2 个 `bifacial` 两面 / Bifacial；≥3 个 `multifacial` 多面 / Multifacial；0 个时整个构型为空。
2. **剥片面**：列出 F1、F2……及各自的面。
3. **剥片面关系** `flaking_surface_relation`（≥2 个剥片面）：两两比较主面，同一根轴上为相对，否则相邻；全部相对 `opposite` 相对 / Opposite，全部相邻 `adjacent` 相邻 / Adjacent，两种都有 `mixed` 混合 / Mixed。
4. **台面关系** `platform_relation`，依次判断：任一剥片面用到的台面 ≥3 个 → `peripheral` 周边 / Peripheral；否则台面面只有 1 个 → `single` 单台面 / Single platform；否则台面面两两比较，规则同第 3 项（`opposite` / `adjacent` / `mixed`）；没有台面面时为空。
5. **总体极性** `polarity`，以整件用到的台面 U 为准：|U| = 1 → `unipolar_longitudinal` 单极纵向 / Unipolar longitudinal；|U| = 2 同轴 → `bipolar_opposed` 对向双极 / Bipolar opposed，不同轴 → `bipolar_orthogonal` 垂直双极 / Bipolar orthogonal；|U| ≥ 3：有任一剥片面向心 → `multipolar_centripetal` 向心多极 / Multipolar centripetal；否则 ≥75% 的片疤方向（投影到所在面）与盒子某根轴夹角 ≤25° → `multipolar_orthogonal` 垂直多极 / Multipolar orthogonal；否则 `multipolar_multidirectional` 多方向多极 / Multipolar multidirectional；|U| = 0 时为空。**向心**：剥片面只有一个面、用到的台面 ≥3 个、≥75% 的片疤朝向该面中心（面内片疤方向与「起点 → 面中心」夹角的余弦 > 0.5）。
6. **剥片面类型** `surface_type`（每个剥片面）：厚度轴 = 盒子最短边的轴；另两边中较短的 ÷ 厚度 < 1.25 → `unclear` 不明显 / Unclear；否则主面垂直于厚度轴 → `wide` 宽面 / Wide，其他 → `narrow` 窄面 / Narrow。
7. **剥片轴** `exploitation_axis`（每个剥片面）：向心、没有用到台面、用到的台面不在同一根轴上 → `na`（显示「—」）；否则 a = 台面所在的轴，b = 主面内与 a 垂直的轴，a 方向盒子长度 ≥ b 方向 → `long` 长轴 / Long，否则 `short` 短轴 / Short。

**阈值常量**：向心的朝向比例 0.75、余弦阈值 0.5；垂直多极的夹角容差 25°、片疤比例 0.75；宽 / 窄面比值阈值 1.25。

### 12.2 双锥的几何（纯函数） ✅ 2026-10-31

### 12.5 不闭合曲线：沿边缘补全一圈 ✅ 2026-10-31

> 完成：compute/completeLoop.ts（分步）；App.completeLoop 吸附、追踪、拉紧后一个 Command 写入；completion 加 userAnchors 记录拖动过的自动锚点；自动段虚线显示；三种失败提示，不留半成品。

用户只画了一段石核边缘，想得到一圈闭合曲线（用于曲线切分、表面分区、计算中心）。

- **入口**：曲线检查器加「补全一圈 / Complete loop」按钮，只在曲线不闭合且至少 3 个锚点时可用。
- **做法**（纯函数部分放 `compute/`；200 万面也不卡，按 `Steps` 分帧或放进 Worker）：① 已画曲线的点做 PCA 得拟合平面，第二主轴方差 / 第一主轴方差 < 0.01（接近直线）时拒绝；② 中心 O = 网格顶点形心投影到平面上，已画曲线绕 O 覆盖的角度 < 90° 时拒绝；③ 沿平面法向看模型，在缺口的角度范围内每约 2° 一个区间，取区间里离 O 最远的顶点，得到俯视轮廓；④ 用现有的吸附（凸 / 棱脊模式）把每个轮廓点吸附到附近的棱脊上作为新锚点；⑤ 用现有的曲线追踪把这些锚点依次连起来，从原曲线的终点一直连回起点，设为闭合。
- **标明自动补出的部分**：曲线加可选字段 `completion: { method: 'outline', firstAutoAnchor: n, stepDeg: 2 }`；自动补出的那段用虚线显示；用户拖动或编辑某个自动锚点后它改为用户锚点，所有自动锚点都变成用户锚点时删除 `completion`。

- **台面线**：把台面段等距重采样为 `FIT_RESAMPLE_COUNT`（200）个点，用整体最小二乘（取主方向）拟合直线，方向取 P→E。
- **结果**：`platform_width_chord` 两端点直线距离；`platform_width_path` 两端点之间、限于台面区域内沿表面的最短路径长；`platform_depth_chord` |PE|；`platform_depth_path` P 到 E、限于台面区域内沿表面的最短路径长；`platform_area` 台面区域的实际表面积；`epa_3pt_1mm`、`epa_3pt_2mm`、`epa_3pt_3mm` EPA 三点法；`epa_2ln_1mm`、`epa_2ln_2mm`、`epa_2ln_3mm` EPA 两线法；`ipa` IPA。
- **EPA**：顶点 E。从 E 沿 S 往离开台面段的方向（背面一侧）走弧长 d，得 Q_d；d 取 `EPA_DISTANCES_MM` = [1, 2, 3]，按坐标单位换算成模型单位。三点法：台面线方向（E→P）与 E→Q_d 的夹角。两线法：在 S 上以 Q_d 为中点、沿折线前后各取 `TWO_LINES_LENGTH_MM / 2`（0.25 mm）得两点，连线作为 Q_d 处的切线，方向背离 E；取台面线方向（E→P）与切线的夹角。折线在走到 d 之前就到头的，该项为空。
- **IPA**：从 P 沿 S 往离开台面段的方向走（腹面一侧），取 Y ∈ `IPA_BAND` × `tech_length` 的部分（`IPA_BAND` = [0.25, 0.75]，避开近端的打击泡和远端的弯曲），重采样为 200 个点，整体最小二乘拟合直线，方向指向 +Y。IPA 是台面线方向（P→E）与这条直线方向的夹角。
- **空值**：没有台面区域或找不到台面段：台面各项都为空。端点不足两个：台面宽两项为空。单位未注明：EPA 六项为空；台面宽、台面深、台面面积、IPA 照算，用模型单位。台面线：找到了台面段就有（台面段有 2 个点就拟合）。腹面中段线：按 25%–75% 截出的折线（含两端的插值点）就拟合，不再数原始点；截出的部分为空时为空（见 18a.2）。
- **沿表面最短路径**（`compute/`）：限于区域内的三角面。先在区域的边图上求最短路径，再把折线在它经过的三角面上拉直。可以复用曲线工具已有的路径代码。
- **实时重算**：技术轴、台面轮廓、端点任何一个变化时都重算。
- **片疤方向**：scar_vectors.csv 末尾加一列 `tech_angle_deg`。石片：把片疤方向投到技术坐标系的 XY 平面，以 +Y 为 0°，从背面看逆时针为正，范围 (−180°, 180°]。石核：为空。
- **默认值**：`FIT_RESAMPLE_COUNT = 200`，`EPA_DISTANCES_MM = [1, 2, 3]`，`TWO_LINES_LENGTH_MM = 0.5`，`IPA_BAND = [0.25, 0.75]`，`STRIP_HALF_WIDTH_RATIO = 0.1`，`STRIP_NORMAL_OUTLIER_DEG = 60`。

3. **t 和 T**：都从参照线量。t 是修理内端处的厚度：背面修理时是 R 到参照线的距离；腹面修理时，过 R 作参照线的垂线，它碰到背面的第一个点 H 到参照线的距离。T = 背面一侧（从 A 走到离开背面为止）各点到参照线距离的最大值；T ≤ 0 时这一站为空。
4. **标本的 GIUR**：每站算 t/T，取所有参与站的简单平均，背面、腹面合在一起；同时给出参与站数。

为空：`no_unit`、`no_faces`、`no_retouch_on_edge`；有修理但没有参与的站时为 `no_unifacial_station`。

### 19.6 分段坐标系 ✅ 2026-11-04

### 19.7 侵入度（Clarkson 2002） ✅ 2026-11-04

> 完成：`segmentOutlineSteps`、`segmentAt`、`penetrationAt`；矩形薄板和阶梯模型符合已知答案。2026-11-04 用户改定：两端段也看到侧缘的距离。

1. **分行**：所有顶点投影到分段坐标系的 XY 平面。长度范围 [y0, y1]，L = y1 − y0。行号 = ⌊5(y − y0)/L⌋，限制在 0–4，第 1 行最靠近端。
2. **轮廓**：所有顶点按 y 分成 `OUTLINE_BINS`（200）格，每格取 x 的最小值 xL(y) 和最大值 xR(y)；中线 mid = (xL + xR)/2，半宽 hw = (xR − xL)/2。再按 x 分成 200 格，每格取 y 的最大值 yTop(x) 和最小值 yBot(x)。空格用相邻格线性插值。
3. **归段**：每个修理三角形（任一层；所在面是背面或腹面；台面上的不算）按形心 (x, y) 归段。第 1 行为段 1，第 5 行为段 8。第 2–4 行按 x 与 mid(y) 比较分左右：左为 2 / 4 / 6，右为 3 / 5 / 7；左右按分段坐标系的 X 定，即背面朝向观察者、近端朝下时的左右。腹面不镜像，段号加 8，为 9–16。
4. **侵入程度 p**（0–1，在边缘为 0，向里增大），用形心计算：到侧缘 p_side = 1 − |x − mid(y)| ÷ hw(y)；第 2–4 行 p = p_side；第 5 行（远端段）p = min(p_side, (yTop(x) − y) ÷ (yTop(x) − (y0 + 0.8L)))；第 1 行（近端段）p = min(p_side, (y − yBot(x)) ÷ ((y0 + 0.2L) − yBot(x)))。各项都限制在 [0, 1]；分母 ≤ 0 时该项为 1。到端缘的一项在行界上为 1，所以 p 跨行连续，p = 0.5 的线在每一面上闭合。
5. **每段得分**：取该段修理三角形 p 的最大值 p_max（没有修理时为 0）。没有修理记 0 分，p_max ≤ `INVASIVE_BOUNDARY`（0.5）记 0.5 分，> 0.5 记 1 分。
6. **两个指数**：侵入度 = 16 段得分之和 ÷ 16；连续侵入度 = 16 段 p_max 之和 ÷ 16。

为空：既没有背面也没有腹面时为 `no_faces`；另有 `no_axis`、`frame_failed`。侵入度不需要单位。

### 19.8 修理周长占比 ✅ 2026-11-04

> 完成：只算类型为 `edge` 的测刃角曲线。

只用类型为 `edge` 且测刃角的曲线。刃缘总长 = 这些曲线所有站的权重之和。修理长度 = 有修理的站的权重之和，两侧都有修理的站只算一次；背面、腹面的修理长度分别按该侧有修理的站算。修理周长占比（0–1）= 修理长度 ÷ 刃缘总长；背面、腹面也各给一个占比。

### 19.9 刃缘弯曲度与修理段 ✅ 2026-11-04

> 完成：`chordDepth`；弦高取绝对值最大的那个点并带符号。修理区域绕闭合曲线一整圈时，弦长、弦高为空。

- **连续修理段**：同一条 `edge` 曲线上相邻的有修理的站连成一段。中间没修理的空隙不超过 `RETOUCH_MERGE_GAP_MM`（2 mm）时，前后两段合并。按权重之和取最长的一段，用来算刃缘弯曲度。
- **平面投影**：这一段各站的刃缘点 A（17a 的 point，为空的跳过）投影到分段坐标系的 XY 平面。
- **R3、R6 和弯曲度**：R3 = 首尾两点之间的距离。R6 = 各点到首尾连线的最大有符号距离；背离轮廓形心（所有顶点 XY 投影的平均值）的一侧为正（凸），朝向形心的一侧为负（凹）。刃缘弯曲度 = R6 ÷ R3。
- 弦长、弦高写成纯函数 `chordDepth(points2d, inside)`，修理段表也用它。
- **修理段表**（每个修理区域一行）：取这个修理区域在每条测刃角曲线上出现的所有站，即它出现在该站修理段里的站；给出起止位置、长度（权重之和）、弦长和弦高；弦长、弦高用这些站的 A 点按位置排序后，按上面的方法算；闭合曲线上跨过起点的，按跨过起点的那一段算；凹缺单独标成一块修理区域时，它的直径和深度就从这一行取。

### 21.1 刃缘的数据 ✅ 2026-11-05

> 完成：`compute/workingEdge.ts`，`SetWorkingEdgesCommand`，顶层 `workingEdges`、`nextWorkingEdgeNumber`。站的权重按该站区间落在刃缘里的比例分（闭合曲线最后一段较短的间隔由首尾两站各分一半），所以各刃缘之和严格等于整条曲线。

**现在的问题**：一件标本上有几条刃缘时（比如双刃刮削器、汇聚刃），刃角、锋利刃缘和修理指数都只能按整条曲线或整件标本给，不能单独测每条刃缘。石片的「边缘」曲线是一整条轮廓，GM 和背腹面划分都依赖它，不能为了分刃缘把它拆开。

- **端点存三维点**，用的时候映射到参考曲线上的位置（最近点）。曲线改动后，端点重新映射。

- **限制**：同一条曲线上的刃缘不能重叠。新建时与已有刃缘重叠就不建，并提示与哪条重叠；拖动端点时不能越过相邻刃缘的端点。最短 `WORKING_EDGE_MIN_MM = 2` mm。曲线删掉时，它上面的刃缘一起删掉，放在同一个 Command 里。曲线不再测刃角时，刃缘保留但不参与计算，检查器里注明原因。

### 21.4 修理指数按刃缘计算（只用于石片） ✅ 2026-11-05

> 完成：`workingEdgeDetails`，由已算好的 `RetouchIndexResult` 分摊，不再切网格；`working_edges.csv`；`derived.workingEdges`；manifest 的 `parameters.workingEdge`。

每条刃缘（包括隐含刃缘）分别算下面几项。站的权重按 21.1。

- **去除体积 RE_k**：刃缘内各站的权重 × 缺失面积之和。缺失面积沿用阶段 19.4 在整条曲线上插值后的值。
- **插值站占比**：刃缘内插值站的权重 ÷ 刃缘内有修理站的权重。超过 `ERP_MAX_FILLED_SHARE`（0.25）时，这条刃缘的 RE 和 ERP 为空（`too_many_gaps`）。整件的值照阶段 19 计算，不受影响。
- **ERP（这条刃缘的贡献）**：RE_k ÷（RE_总 + V）。RE_总 是阶段 19.4 整件的去除体积，V 是模型体积。这样定义，各刃缘的 ERP 相加等于整件 ERP（减去不在任何刃缘里的站）。为空的规则同阶段 19.4。
- **GIUR**：刃缘内所有参与站的 t/T 的简单平均，加参与站数。参与条件同阶段 19.5。
- **修理周长占比**：刃缘内有修理的站的权重 ÷ 刃缘长度；背面、腹面各一个占比。
- **刃缘弯曲度**：用这条刃缘自身的全部站（不论有没有修理），各站的 A 点投影到分段坐标系的 XY 平面，按阶段 19.9 的 `chordDepth` 算 R3、R6 和 R6/R3。隐含刃缘是整条闭合曲线时为空（`whole_edge`）。整件的刃缘弯曲度仍按阶段 19.9，取最长修理段。
- **锋利长度**：刃缘内锋利段的长度（所有标本类型都给，阈值未设时为空）。
- 侵入度只按整件算，不分刃缘。

**导出：新文件 `working_edges.csv`**，每条刃缘一行，隐含刃缘也算：`specimen_id, working_edge, name, curve_id, start_position, end_position, length, sharp_length, retouched_length, retouch_perimeter, retouch_perimeter_dorsal, retouch_perimeter_ventral, removed_volume, erp, erp_filled_share, giur, giur_stations, edge_curvature, edge_curvature_chord, edge_curvature_depth`。
